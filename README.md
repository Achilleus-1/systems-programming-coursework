# Systems Programming Coursework

Bash, Sed, Awk, Python, and C programs for record management, text processing, binary file I/O, and process control.

## Original coursework

- Systems Programming

Originally completed at the University of Texas at San Antonio and imported to GitHub later. This repository retains the coursework implementation with documented maintenance fixes and demonstration assets.

**Languages and technologies:** Bash, Sed, Awk, Python, C, POSIX APIs, Make.

## Implementation

- A Bash course-record CRUD/enrollment tool.
- Sed and Awk text-processing scripts.
- CSV call-log summaries in Python.
- Binary course-record storage in C and a process-control exercise.

## Concepts

- Shell composition, regular expressions, aggregation, binary record offsets, fork/exec, pipes, and process coordination.

## Repository layout

| Directory | Contents |
|---|---|
| `course-records-bash` | Bash record management |
| `sed-text-processing` | Sed command script |
| `awk-text-processing` | Awk aggregation |
| `call-log-analysis` | Python CSV summaries |
| `binary-course-records` | C file I/O |
| `process-control` | C process-control implementation |

## Running the source

Use a Unix-like environment for Bash/Sed/Awk and the POSIX C program. Run scripts within their exercise directories. The Python CSV analyzer accepts a data file or directory argument.

## Scope and limitations

- A Unix/POSIX environment is required for process-control; a Windows-only toolchain is insufficient.
- Original output logs and command transcripts were excluded.

Only source code, build configuration, and required text inputs are included. Written submissions, assignment instructions, PDFs, videos, generated outputs, binary builds, and private configuration are omitted. Anonymized contributor labels and supplied-code comments retain the distinction between submitted work and scaffolding. No license for course-provided material is inferred.
